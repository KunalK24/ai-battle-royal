# ai-battle-royal

## Server Environment

```txt
PORT=3000
ADMIN_PASSWORD=dev-admin-password
AGENT_MODE=mock
OPENAI_API_KEY=
OPENAI_MODEL=gpt-5.2
PYTHON_COMMAND=python3
SKIRMISH_TIMEOUT_MS=60000
CODE_TIMEOUT_MS=3000
MAX_OUTPUT_BYTES=4096
MAX_GENERATED_CODE_CHARS=12000
```

On Windows local development, set `PYTHON_COMMAND=py` if `python3` resolves to the Python install manager instead of a real interpreter.
